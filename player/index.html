Beim ersten Start

  • Paket auspacken und das Programm starten – eine Installation gibt es nicht.
  • Die Testversion hat noch kein Zertifikat, deshalb warnt das System einmal. Windows: „Weitere Informationen", dann „Trotzdem ausführen". Mac: Rechtsklick auf das Programm, dann „Öffnen".
  • Beim ersten Start öffnet sich das Testprojekt „Weismehl Demo".
  • Fehler und Wünsche: der Knopf „Feedback" oben im Programm.
